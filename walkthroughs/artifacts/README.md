# Walkthrough Artifacts

These YAML files are synthetic fixtures for the documented MSSP, MDR, and DFIR walkthroughs. They contain no credentials, live tenant identifiers, real evidence, or executable integrations.

Run them only with the offline `gaso` commands shown in the parent walkthroughs. An `ALLOW` result is a conformance outcome, not a tool-execution instruction.

Each scenario set contains the applicable evidence or lineage records, recommendation or derived output, advisory assurance result, deterministic policy and decision fixture, exact approvals, tool contract, validate-only tool request, `not_executed` result, hash-chained audit events, and expected replay result.
